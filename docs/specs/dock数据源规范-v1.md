# dock 数据源规范 · v1（U3 左右侧栏 · 桌面级侧栏卡）

> **提出**：workbuddy（云昔）· U3 数据侧（拍案 1 号：U3 schema=知默已会签 · 视图=豆包 · **数据侧=我**）
> **时间**：2026-09-24 ｜ **状态**：v1 草案（候 schema 正式稿与视图侧评议）
> **目的**：让 `desktop.dock-left / desktop.dock-right` 两个桌面级侧栏的卡片，以**统一、可降级**的方式由各插件提供。

---

## 1. 与 E5 的关系（同一机制，两级挂载点）

| | E5 `window.sidecar` | **U3 `desktop.dock-*`** |
|:--|:--|:--|
| 挂载范围 | **单个窗口内**的侧栏 | **整个桌面**的左右侧栏 |
| 声明方式 | 插件 `slots` 数组 | 同（slot 枚举扩张，知默已会签） |
| 组件提供 | `entry` 组件 `mod.default.slots` | 同 |
| 先例 | — | **C 里程碑侧栏卡**（豆包，第一个 dock 类实例） |

★ **机制零新增**：只是 **slot 枚举加两个名字** —— E5 跑通的声明→注册→挂载链路原样复用。

## 2. 卡片数据形状（与 todaySummary 同构）

```jsonc
{
  "title": "里程碑",                 // 卡片标题
  "items": [                         // 可为空 = 今天没内容
    {"text": "距主人唤醒日 152 天", "state": "info", "count": 152}
  ],
  "link": "/countdown"               // 点击卡片头部跳转
}
```

- **形状与 `todaySummary` v1 完全一致**（title/items[].text/state/count/link）→ **视图组件一套代码两处用**
- `items` ≤ **6** 条（侧栏空间有限）；超出请聚合

## 3. 三态语义（与 todaySummary 相同，一字不改）

**未实现（404）/ 已挂载但无内容（空 items）/ 有内容** —— **"没装"≠"没内容"**，视图必须可区分。

## 4. 布局判据（业界要点，拍案已采纳）

| 判据 | 值 |
|:--|:--|
| 每侧卡片上限 | **≤ 3**（超出按声明顺序截断 + 记 warning）|
| 展开宽 / 折叠宽 | 220-280px / 56-72px（图标态）|
| **折叠状态持久化** | localStorage，**跨会话保持** |
| 折叠态 tooltip | **必须**（纯图标无标签 = 学习税）|
| 过渡 | 200-300ms |
| <768px | 转抽屉/隐藏（侧栏模式移动端失效）|
| 无障碍 | `aria-expanded` · 可见 focus 环 · Escape 收起 |

**过载守门**：dock 卡总数（两侧合计）> 6 时，`export_capability_map` 的 audit 应报 warning（**工具升级候做**）。
